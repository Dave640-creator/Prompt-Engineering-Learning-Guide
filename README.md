# 🤖 AI Engineering Bucket

> A structured collection of notes, examples, experiments, exercises, and projects for learning modern AI Engineering — from AI and LLM fundamentals to prompt engineering, context engineering, RAG, AI agents, evaluation, security, and production-ready AI applications.

---

## 📖 About

This repository documents my journey in learning **AI Engineering**.

It serves as a centralized knowledge base for organizing:

- 📖 Concepts and technical notes
- 📝 Documentation
- 💡 Examples
- 🧪 Experiments
- 💻 Code implementations
- 🧠 Prompt patterns
- 🔧 AI tools and APIs
- 🎯 Exercises and assessments
- 🚀 Real-world projects
- 📑 Cheat sheets
- 📊 Evaluation methods
- 🔐 AI security practices

The goal is to understand not only how **Artificial Intelligence and Large Language Models (LLMs)** work, but also how to use them effectively to build **reliable, scalable, secure, and production-ready AI applications**.
